# simulador-fatura-cartao
📌 Sobre o projeto  Este projeto foi desenvolvido em Python a partir de uma situação real vivenciada durante meu trabalho como Operador de Relacionamento em uma empresa do setor de cartões de crédito.  Durante um atendimento, um cliente sugeriu uma funcionalidade que não estava disponível no aplicativo da empresa: visualizar de forma clara como os juros seriam aplicados em caso de atraso da fatura, bem como o valor atualizado da dívida ao longo do tempo.  A ideia chamou minha atenção e decidi transformá-la em um projeto prático utilizando Python.  Em vez de reproduzir apenas a solicitação do cliente, expandi a proposta e desenvolvi um sistema mais completo, simulando diversas análises que poderiam fazer parte de uma solução utilizada por uma instituição financeira.  🎯 Objetivos  O sistema realiza o cadastro do cliente e executa uma análise completa da situação da fatura, permitindo visualizar informações importantes antes do pagamento.  Entre as funcionalidades implementadas estão:  Cadastro do cliente Cadastro dos dados do cartão Registro da fatura Pagamento parcial da fatura Cálculo do saldo restante Análise da utilização do limite do cartão Cálculo automático dos juros conforme os dias em atraso Cálculo do valor atualizado da dívida Classificação do nível de inadimplência Análise do comprometimento da renda Programa de benefícios para clientes adimplentes Relatório completo contendo todas as informações calculadas 🛠 Tecnologias utilizadas Python Random Time Estruturas condicionais (if, elif, else) Laços de repetição (while) Operações matemáticas Regras de negócio Validação de dados Organização de código 💡 Motivação  Mais do que praticar programação, este projeto teve como objetivo transformar uma necessidade observada em um atendimento real em uma solução de software.  Foi um excelente exercício para desenvolver lógica de programação, modelagem de regras de negócio e organização de código, aproximando o estudo de um cenário encontrado no mercado financeiro.  📚 Conceitos praticados Lógica de programação Estruturas de decisão Estruturas de repetição Validação de entradas Cálculos financeiros Organização de sistemas Simulação de processos bancários Desenvolvimento baseado em problemas reais 🚀 Próximas melhorias  Pretendo evoluir este projeto adicionando novas funcionalidades, como:  Interface gráfica Persistência de dados Histórico de clientes Exportação de relatórios Integração com banco de dados API para consulta de faturas Simulação de negociação da dívida Geração de score financeiro.
